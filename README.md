# 3D Solar System — 3D交互式太阳系模拟系统

基于 Three.js 的 3D 太阳系可视化与天文科普平台，支持实时时间同步、精确轨道计算、天体信息查询与时间穿越。

## 功能特性

- **精确天文计算**：基于 J2000 历元与开普勒方程求解，实时计算八大行星与月球的轨道位置
- **日下点差量校准法**：独创的地球日照同步算法，使模型地球的昼夜分界线与现实 UTC 时间完全对应
- **时间控制系统**：支持实时同步、时间倒退/前进（从秒级到年级共 57 个档位）、暂停等操作
- **天体信息面板**：点击任意天体查看物理参数、轨道数据、神话背景、探测历史等详细信息
- **视距剔除优化**：根据相机距离自动隐藏远处天体，保证流畅渲染
- **标签遮挡检测**：射线检测实现标签被天体遮挡时自动透明化
- **搜索导航**：支持中英文搜索天体并平滑导航聚焦
- **响应式交互**：支持鼠标与触屏操作，适配移动端

## 快速开始

项目为纯静态站点，无需构建。

### 方式一：直接打开

用浏览器打开 `index.html` 即可（部分浏览器对本地 ES Module 有限制，推荐使用本地服务器）。

### 方式二：本地服务器（推荐）

```bash
# 使用 Python
python -m http.server 5503

# 或使用 Node.js
npx serve
```

然后访问 `http://localhost:5503`。

### 方式三：VS Code Live Server

项目已配置 `.vscode/settings.json`，端口 5503。安装 Live Server 插件后右键 `index.html` 选择 "Open with Live Server"。

## 核心算法说明

### 日下点差量校准法

项目核心创新点，位于 `src/js/utils.js`。通过比较地球模型的当前日下点经度与真实日下点经度，计算校准旋转角度，使 3D 模型的昼夜状态与现实地球完全同步。详见 [日下点校准法使用说明.md](./日下点校准法使用说明.md)。

### 轨道位置计算

基于 J2000.0 历元的轨道六要素（半长轴、偏心率、倾角、平黄经、近日点黄经、升交点黄经），通过解开普勒方程求得偏近点角，再转换到天球赤道坐标系。支持长期变化（每世纪变化率）。
